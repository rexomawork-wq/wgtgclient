# site-67 — СИКС-СЕВЕН лендинг

Мем-лендинг про «67» на React + Vite. Живёт отдельной папкой, на сборку Telegram-клиента не влияет.

## Запуск

```sh
cd site-67
npm install
npm run dev    # http://localhost:5173
npm run build  # продакшен в site-67/dist/
```

## Состав

- `index.html` — вход
- `src/App.jsx` — hero, история мема, кликер до 67, гайд, FAQ
- `src/index.css`, `src/main.jsx`
- `vite.config.js`, `package.json`
